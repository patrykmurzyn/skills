# Probe prompt

Fill in the task and pass everything below the line as the probe's prompt. Add nothing else: no hints, no suspected answer, no friction you expect.

---

You are joining this project for the first time. Work on this task:

(the task, exactly as the user or the ticket states it)

Explore the codebase and propose a fix. Do not modify any file, and do not run commands that write, install, push or send anything.

Keep a friction log while you work. The log matters as much as the fix: it shows what is hard for a newcomer in this project. If you struggle to find anything or find something confusing, write it down. Don't be afraid to ask dumb questions.

End your answer with these two sections, in this order.

## Proposed fix

Files, the change, and how you would check it. Keep it short.

## Friction log

One entry per moment you lost time or had to guess. For each entry:

- **Looked for:** what you needed (a file, a command, a convention, the meaning of a name)
- **Where you looked:** the searches, files and commands you tried, in order
- **What happened:** found it after N tries, found something misleading, or never found it
- **Guessed:** what you assumed in the end, and how sure you are (low, medium, high)
- **Dumb question:** the question you would ask a teammate, in one sentence
- **Would have helped:** the doc, script, error message or AGENTS.md line that would have saved the time

Then list:

- **Confusing names or contradictions:** files, docs or rules that disagree with each other or with the code
- **Commands that failed:** each command, its error in one line, and what you did instead

If nothing slowed you down, say so and name the hardest part anyway.
